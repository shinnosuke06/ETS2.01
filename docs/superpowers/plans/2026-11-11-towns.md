# 町の道と倉庫 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 13 の IC の先に、交差点・信号・周りの車・倉庫（荷台口と納品の枠）のある町を作り、仕事を「出発の町の倉庫で連結 → 町 → 入口から合流 → 高速 → 出口 → 町 → 目的の倉庫で納品」にする。

**Architecture:** 町の形は DOM なしのデータ（`02b-towns.js`）として作り、物理は新しい窓口 `GROUND`（`02c-ground.js`）に地点ごとの地面と壁を聞く。高速では `ROAD` から今と同じ答えを返す。町のルール（信号、町の車、荷台口、赤信号）も DOM なし（`02d-town-flow.js`）。見た目（`05b-town-mesh.js`、`10b-town-traffic.js`）とゲームの流れ（`13-game.js`）は最後につなぐ。

**Tech Stack:** Three.js r128（CDN、テストは npm の `three@0.128.0`）、素の JavaScript（グローバルスコープのスクリプトを `build.mjs` が名前順につなぐ）、`node --test`、Playwright（headless Chromium + swiftshader）。

**Spec:** `docs/superpowers/specs/2026-11-11-towns-design.md`

## Global Constraints

- ゲームは 1 つの HTML にまとまる。形もテクスチャもコードで作る。外部の 3D モデル・画像は読み込まない。
- 実在の会社名・店名・車種名・紋章は入れない。倉庫の名前は「〇〇物流センター」など架空（`test/names.test.mjs` が見張っている）。
- 車の挙動は変えない：`RIGP`、タイヤ、連結、安定装置、`powertrainStep` の計算に触れない。変えるのは「地面と壁を聞く所」だけ。
- 高速の本線の形・景色・トンネルは変えない。変えるのは出入口の帯（3 章）と、町の範囲の地形・木・家。
- 座標：本線の位置 `s`（m）、横の位置 `lat`（左が負）。町の座標 `u`（本線の向き、西向きが正）、`v`（本線から離れる左向きが正）。原点は `posAt(ic.s + 125, −40)`。町の中の長さは実寸、高速の距離は 1:10（`SCALE = 10`）、時計は 10 倍（`TIME_SCALE = 10`）。
- 出入口：出口の帯 `ic.s − 500`〜`ic.s + 100`（`RAMP_LEN = 600`）、入口の帯 `ic.s + 150`〜`ic.s + 600`（`ENTRY_LEN = 450`：本線へ寄る 250 m、加速車線 200 m）。東京は入口だけ、名古屋は出口だけ。
- 町の範囲：`u = −300〜+300`、`v = 5〜405`。`|u| ≤ 60` だけ `v = −8` まで。料金所広場 `u = −50〜+50`、`v = 5〜45`。建物・柵・構内は本線と出入口の帯から 15 m 以上。
- 町の地図：50 cm のマス、1,200 × 826 マス。種類 `OUT 0`、`ROAD 1`、`WALK 2`、`YARD 3`、`WALL 4`。壁までの符号つき距離（cm、`Int16`、±600 で止める）。1 町 4 MB 以下、同時に 2 町まで。
- 道：大通り 片側 2 車線（車線 3.25 m、歩道 3.5 m、制限 50）、脇道 片側 1 車線（車線 3.0 m、歩道 2.5 m、制限 40）、構内 20 km/h。交差点の角の丸み 12 m。縁石 15 cm（乗り上げられる）。
- 信号：70 秒周期。`v` 方向 青 0〜30 秒、黄 30〜33、全赤 33〜35、`u` 方向 青 35〜65、黄 65〜68、全赤 68〜70。交差点ごとに決まったずれ。
- 罰金：赤信号 ¥9,000（同じ交差点は 30 秒あける）、速度超過 ¥9,000（制限 +12 km/h が 4 秒、45 秒あける）、料金所のバーに接触 ¥8,000（今と同じ）。歩道は罰金なし。違う IC で降りても罰金なし。
- 荷台口：トレーラーの後ろの端が当て物から 0.6 m 以内、横のずれ 0.5 m 以内、向きの差 4° 以内。報酬の基本額の 20% を足す。納品の枠：4 m × 18 m、キングピンと後ろの端が中。
- 町の車：画質 高 25／中 20／低 15 台。上限（町 1 つ）：三角形 高 150,000／中 90,000／低 50,000、描く回数 90 以下。町は広場から 2.5 km で作り始め、3.5 km で片付ける。作る仕事は 1 回 30 ms 以内（テスト環境）。
- 保存：`nlh.drive` に `{ job, x, z, h, v, link, trailer: { x, z, h }, clock, money }` を 10 秒ごとと `pagehide` で。`nlh.money`・`nlh.job` は今のまま（`nlh.job` は 13 で割った余り）。
- ソースはグローバルスコープ。ファイルをまたいで同じ名前の `const`／`let`／`function` を作らない（`test/math.test.mjs` の全ファイルをつなぐテストが見張っている）。DOM なしのファイル（`01a`、`02*`、`09a`〜`09c`）は Node のテストで読む（`test/helpers/sim.mjs` の `PURE`）。
- テストは今ある 119 件（`npm test` 62 件、`npm run e2e` 57 件）が通り続ける。流れが変わるテストは Task 7 で新しい流れに書き直す。e2e は 1 ファイル 10 分まで（`--test-timeout=600000`）。長くなったらファイルを分ける。
- コミットのたびに `npm run build` で `index.html` を作り直して一緒にコミットし、`git push -u origin claude/nippon-long-haul-game` する。プルリクエストは作らない。コミットメッセージの最後に、セッションの指示にある帰属の 2 行を付ける。

**Interfaces:**
- Consumes: `ROAD.project`、`ROAD.drivable`、`ROAD.headingAt`、`ROAD.gradeAt`、`ROAD.elevAt`、`ROAD.barrier`。
- Produces:
  - `GROUND.at(x, z, hint, out)` → `out = { y, gx, gz, zone, town, s, lat, i }`。高速では `y = ROAD.elevAt(s)`、`(gx, gz) = gradeAt(s) · (sin h, cos h)`（`h = headingAt(s)`）、`zone = 'road'`、`town = −1`。
  - `GROUND.contact(x, z, hint, out)` → `out = { pen, nx, nz, tx, tz, i }`。高速では今の `rigCorner` の中身と同じ：いちばん近い走れる区間からはみ出した長さ `pen`、押し返す向き `n = (−dir·cos h, dir·sin h)`、沿う向き `t = (sin h, cos h)`。はみ出していなければ `pen = 0`。
  - `GROUND.barrier(x, z, hint)` → `ROAD.project` した `s` から `ROAD.barrier(s, lat)` を引いた値（正ならめり込み）。
  - `GROUND.towns = []`（Task 3 で町を足す）。
  - `ROAD` を差し替えると `GROUND` の答えも変わる（`GROUND` は呼ばれるたびに `ROAD` を見る）。
