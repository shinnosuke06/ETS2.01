# ナビ 設計書

- 日付：2026-11-12
- 対象：ニッポン長距離便（`ETS2.01`、ブラウザ版）
- 位置づけ：「道路・建物・ナビ」を 4 つに分けたうちの 2 つ目（C2）。C1「町の道と倉庫」は完成。残りは C3「高速道路（サービスエリア、給油と休憩、道路の小物、夜の照明）」、C4「建物と景色」。

## 1. 目的

初めての町でも、案内だけを見て目的の倉庫まで行けるようにする。

- 町の中では、次に曲がる交差点の矢印・距離・使う車線を前もって出す。
- 高速では、降りる IC と車線を前もって出す。
- 道を外れたら、今いる所から自動で道を探し直す。
- 全体地図で、今いる所・目的地・通る道を見られる。

### 承認済みの方針

| 項目 | 決定 |
| --- | --- |
| 作るもの | 町の地図と曲がる案内、車線の案内、全体地図の画面。音声なし |
| 案内を出す場所 | 車内の画面（今のナビ画面）＋どの視点でも見える小さな札 |
| 全体地図 | 「地図」ボタン（PC は M キー）で開く。開いている間はゲームが止まる |
| 町の道の選び方 | 大通り優先・右折少なめ（少し遠回りでも曲がりやすい道） |
| 作り方 | 案 1「交差点のつながり表」。車線は次に曲がる向きから決める |
| 道を外れたら | 自動で探し直す |

### 今回やらないこと

- 音声の案内。
- 道路の上に描く矢印や、3D の案内線。
- 渋滞の情報、目的地を自分で選ぶ機能、寄り道（サービスエリアは C3）。
- 高速の車が合流するトラックに道を譲る動き（C3 で考える）。
- 建物の名前や店の名前を地図に出すこと（C4 で建物ができてから）。

## 2. プレイヤーから見た変化

- 町の交差点の 300 m 手前から、「左折」「右折」「直進」の矢印と距離が出る。大通りでは、どちらの車線を走ればよいかが 2 つの枠で出る。
- 曲がり損ねても、2 秒ほどで新しい道に切り替わり、「ルートを探し直しました」と出る。
- 高速では、目的の出口の 2 km 手前から「〇〇IC 出口 左車線へ」と車線の絵が出る。
- 運転席の画面には、通る道が太い青い線で描かれる。目的の構内では荷台口（オレンジ）と納品の枠（青）に印が付く。
- どの視点でも、画面の右上（ボタンの下）に小さな案内の札が出る（曲がる手前、出口の手前、広場と構内）。スマホの後ろからの視点でも案内が見える。
- 「地図」ボタンで全体地図が開き、ゲームが止まる。上に東名の線と 13 の IC、下に町の地図とルート。

## 3. 道探し

### 3.1 町のつながり表

- 町ごとに、交差点（`layout.nodes`）と、そのあいだの道を「向きのある道」として表にする（行きと帰りは別の道）。
- 道の向きは `'v+' | 'v-' | 'u+' | 'u-'`（町の座標、C1 と同じ）。長さは交差点の中心どうしの距離。
- 町の端で閉鎖されている道の先（交差点のない端）は表に入れない（トレーラーは向きを変えられない）。
- 料金所広場の口（大通り A の `v = 45`）を特別な点「広場」とし、大通り A の最初の交差点とのあいだを道でつなぐ（広場から出る向きと入る向き）。
- 表は `layout` ごとに 1 度作って覚えておく（町を作り直したら作り直す）。

### 3.2 点数

道の点数は小さいほどよい。

- 距離（m）×（大通り 1.0、脇道 1.4）。
- 交差点で左折 +15、右折 +60、直進 0。
- 倉庫の門に入るとき・門から出るときも、左に入る（出る）なら +15、右なら +60。
- U ターンは計画しない。

例：右折 1 回で済む道と、左折 3 回で 300 m 遠回りする道なら、右折の道を選ぶ。

### 3.3 始まりと終わり

- 始まり：今いる道と向き、道の上の位置（3.4）。または倉庫の門（出発の構内から出るとき）。
- 終わり：目的の倉庫の門（道の途中の点）。または「広場」（高速に戻るとき）。
- 倉庫の門は、門のある道の、門の位置の点。どちらの向きから来たかで、門に入るのが左か右かが決まる。

### 3.4 道の上の位置合わせ

- トラックの前の点（`RIGP.front` だけ前）を町の座標にし、近い道の中心線に投げる。道の幅（車道＋歩道、`_ht`）の中なら「その道の上」。
- 向きは、道の 2 つの向きのうち、トラックの向きとの差が 60° より小さい方。どちらも 60° 以上（交差点の中で曲がっている途中など）なら、直前の結果をそのまま使う。
- 交差点の中（2 本の道の幅が重なる所）、広場、構内では、直前の道を使い続ける。

### 3.5 探し直し

次のどれかで、今いる道と向きから探し直す。

- ルートの次の交差点を過ぎたあと、ルートと違う道に入った。
- ルートの道の上を、ルートと逆の向きに 15 m 以上走った。
- ルートの道から 20 m 以上離れたまま 2 秒たった（構内と広場は除く）。

探し直したら「ルートを探し直しました」を 2 秒出す。続けて探し直すときは 3 秒あける。交差点は十数か所なので、1 回の探索は 1 ms 未満。

### 3.6 高速

- 一本道なので探さない。入口の帯 → 本線 → 目的の出口ランプの順に案内する。
- 目的の出口を過ぎたときと、目的の町から入口で高速に戻ったときは、C1 の決まりで次の IC が目的地になり、案内もそれに合わせる。
- 目的地でない IC で降りた町では、ルートの終わりを「広場」にして入口へ案内する（C1 と同じ考え方）。

## 4. 案内の中身

### 4.1 区間

仕事の道を、今いる所から次のどれかに分けて案内する。

| 区間 | どこ | 案内 |
| --- | --- | --- |
| 出発の構内 | 出発の倉庫の構内 | 「門を出て左」「門を出て右」 |
| 町 | 町の道の上 | 4.2 |
| 広場 | 料金所広場 | 「ETC 入口 20km/h 以下」（入口へ）、「ETC 出口 20km/h 以下」（出口から町へ） |
| 入口の帯 | 入口ランプ | 「本線へ合流　右」 |
| 高速 | 本線 | 4.3 |
| 出口ランプ | 目的の出口ランプ | 「料金所 ETC は 20km/h 以下」（今のまま） |
| 目的の構内 | 目的の倉庫の構内 | 「荷台口にバックで（+20%）」と、いちばん近い荷台口までの距離。または「納品の枠へ」 |

トレーラーをまだ連結していないときは、どの区間でも「トレーラーを連結してください」を先に出す（今のまま）。

### 4.2 町の中

- 次の操作：「左折」「右折」「直進」「門は左」「門は右」「広場へ」。矢印と、交差点の中心（門なら門の中心）までの距離（10 m 単位）。
- 300 m より遠いときは「直進」と距離だけ。小さな札は出さない。
- 次の操作から 60 m 以内に次の曲がりが続くときは、「その先 右」のように小さく添える。
- 車線（大通り、片側 2 車線）：2 つの枠を並べる。左の枠は「左・直進」、右の枠は「直進・右」の矢印。使う枠を明るくする。
  - 左折・門は左：左の枠。
  - 右折・門は右：右の枠。
  - 直進：両方。
- 脇道（片側 1 車線）では車線の絵は出さない。

### 4.3 高速

- ふだん：「次 〇〇IC　そのまま直進」と距離（今のまま）。
- 目的の出口の 2 km 手前から：「〇〇IC 出口　左車線へ」と、2 車線の絵（左を明るく）。小さな札も出す。
- 出口の分かれ目の 300 m 手前から：「出口　左」と分かれ目までの距離。

## 5. 表示

### 5.1 運転席の画面（`drawNav`）

- 上の帯：左に大きな矢印（4 章の操作）、右に距離。帯の下の左に車線の絵（あるとき）。
- 地図：町の中は 0.35 px/m（今のまま）。通る道を太い青い線（6 px）で、灰色の道の上に描く。
- 目的の構内：荷台口はオレンジの四角、納品の枠は青い枠線。
- 高速：今の描き方のまま、目的の出口まで青い線。
- 下の帯：今のまま（目的地までの距離と到着予定）。

### 5.2 小さな札（どの視点でも）

- 画面の右上、ボタンの並び（`#topbar`）のすぐ下に出す。縦持ちのスマホでは、ボタンの並びの下の右端。
- 中身：矢印（大きさ 44 px）、距離、車線の絵（あるとき）、「その先 右」（あるとき）、探し直しの知らせ（2 秒）。
- 出るとき：町で曲がる 300 m 手前から、高速で目的の出口の 2 km 手前から、広場と構内。そのほかは隠す。
- ボタン、目的地の札（`#jobSign`）、LED の知らせ（`#led`）と重ならない。

### 5.3 全体地図

- ボタンの並びに「地図」を足す（「メニュー」の左）。PC は M キー。もう一度押す、M、Esc で閉じる。
- 開いている間はゲームが止まる（メニューと同じく `GAME.state` を変え、閉じたら前の状態に戻す）。メニューと同時には開かない。
- 中身（1 枚の絵）：
  - 上：東名の線（東京から名古屋まで）、13 の IC の点と名前、出発と目的の IC の色分け、今いる所の印。
  - 下：今いる町の地図。高速にいるときは目的の町の地図。道、倉庫の構内、広場、通る道（青）、今いる所と向き。
- スマホの縦・横どちらでも、画面に収まる大きさで描く。

## 6. データの形

### 6.1 `src/02e-nav.js`（画面を使わない）

```js
navGraph(layout)            // → { nodes: [{ id, u, v }], edges: [{ id, from, to, street, dir, len, main, a: [u, v], b: [u, v] }], out: Map(node → [edge ids]), plaza: nodeId }
navRoute(layout, from, to)  // from: { edge, d } または { gate: wh } ／ to: { gate: wh } または { plaza: true }
                            // → { edges: [ids], cost, steps: [{ kind, at: [u, v], edge }] } または null
navMatch(layout, u, v, h, prev)   // → { edge, d, off } または null（交差点の中・広場・構内は prev のまま）
navGuide(layout, route, match)    // → { kind, dist, then: { kind, dist } | null, lanes: [{ arrows, use }] | null }
```

- `kind`：`'left' | 'right' | 'straight' | 'gateLeft' | 'gateRight' | 'plaza' | 'arrive'`。
- `lanes`：大通りのときだけ。左の枠 `{ arrows: ['left', 'straight'] }`、右の枠 `{ arrows: ['straight', 'right'] }`、`use` が明るくする枠。
- どれも Node のテストでそのまま読み込める（`test/helpers/sim.mjs` の PURE に足す）。

### 6.2 ゲームの中の状態（`13-game.js`）

- `NAV = { leg, route, routeOf, match, offT, rerouteT, msgT }`。`leg` は 4.1 の区間。`routeOf` はルートを作ったときの町と終わり。
- `navState()` は今の値に、`maneuver`（矢印・距離・その先・車線）、`card`（小さな札を出すか）、`routePts`（青い線の点、町の座標）を足す。
- ルートは、町に入ったとき・終わりが変わったとき・探し直しのときだけ作る。毎フレームは位置合わせと案内だけ。

## 9. 上限

- 道探し：1 回 1 ms 未満。
- 運転席の画面の描画：1 回 3 ms 以内（今の間隔 0.2 秒ごと、後ろからの視点では 0.6 秒ごとのまま）。
- 小さな札：0.2 秒ごとに文字と矢印を入れ替えるだけ（絵を毎フレーム作らない）。
- 全体地図：開いたときに 1 度描く（30 ms 以内）。

## 10. エラーへの備え

- ルートが見つからない（町を作るのに失敗して「簡単な構内」になったときなど）：C1 の仮の案内（「〇〇まで 〇 m」と方向の矢印）に戻す。
- 位置合わせができない（町の外れ、草地）：直前の結果を使い、20 m・2 秒の決まりで探し直す。それでも合わなければ仮の案内。
- 案内で例外が出ても、運転は止めない（その回の案内を前の値のままにして、コンソールに 1 行出す）。
