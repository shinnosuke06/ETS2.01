# トラックの外観と室内 設計書

- 日付：2026-11-10
- 対象：ニッポン長距離便（`ETS2.01`、ブラウザ版）
- 位置づけ：ゲームの作り込みを3つに分けたうちの2つ目。1つ目「牽引の重さと挙動」は完成。残りは「道路・建物・ナビ」で、別の設計書を書く。

## 1. 目的

ユーザーの写真 9 枚（Sシリーズのトラクター、室内 3 枚・外観 6 枚）に見える車両にする。

- 室内（運転席から見える範囲）を最優先で作り込む。外観はその次。
- 今の車両は部品がひととおりあるが、平らな箱の組み合わせで、色も暗い灰色一色に見える。これを、曲面の形・素材の質感・窓から入る光で作り直す。
- スマホでも動く軽さを保つ。ゲームは今までどおり 1 つの HTML ファイルにまとまる。

### 承認済みの方針

| 項目 | 決定 |
| --- | --- |
| 優先順位 | 室内を最優先、外観はその次 |
| 室内の範囲 | 見た目だけを徹底的に作る。動く部品は今と同じ（ハンドル、ペダル、計器、ナビ、ミラー、お守り） |
| 外観の姿 | 「ノーマル」と「飾り付き」をメニューで切り替える |
| 作り方 | 部品を曲面で作り直す。革・樹脂・金属の質感、塗装の映り込み、窓から入る光も入れる |
| ロゴと社名 | 入れない。グリル、キャブの後ろ、泥よけ、ハンドル中央は無地にする |

### 今回やらないこと

- 動く・光る部品を増やすこと（レバーやスイッチの操作、座席の位置調整、ドアの開閉、室内灯のスイッチ）。
- トレーラー（バン、タンク）と、周りの車の作り直し。
- 外で作った 3D モデルや画像ファイルの読み込み。形もテクスチャも、すべてコードで作る。
- 傷やへこみの表示。
- 物理の変更。車体の外寸（幅、前端、ホイールベース、連結点）は今のまま。
- 画面全体の色の出し方（明るさの計算）の変更。道路や建物の見え方は今のまま。

## 2. プレイヤーから見た変化

1. 車内視点：運転席を囲む曲面のダッシュボード、革巻きのハンドル、張り出しのあるシート、ドアの内張り、頭上の収納、ベッドが、写真の配置と形で見える。窓から入る光で、部品に明るい面と暗い面ができる。
2. 外の視点：キャブにドアの線、ステップ、導風板、丸いフェンダーが付き、塗装に空が映る。ホイールやタンクは金属に見える。
3. メニューとタイトル画面に「外装の仕様：ノーマル／飾り付き」が増える。外装色 4 色と内装 3 種類は今までどおり選べる。
4. 夜：計器と画面の光、足元と頭上の赤い間接照明（ライトが点くと自動で点く。今と同じ）。
5. 画質設定：「高」「中」は質感と映り込みあり。「低」は軽い素材になるが、形は同じ。

## 3. 寸法と座標（今のまま）

- 座標：原点は後軸の中心の真下の地面。前が −z、右が +x、上が +y。
- キャブ：前面 z = −5.40、後面 z = −3.12、全幅 2.50、屋根の上 y = 4.02。右ハンドル。
- 室内：床 y = 1.45、天井 y = 3.80、内側の幅 2.36、前の壁 z = −5.31、後ろの壁 z ≈ −3.19。運転席 x = +0.55、助手席 x = −0.60、ベッドは z = −3.5 付近。
- 目の位置：(0.55, 2.62, −4.28)。今の `INT.eye` のまま。
- シャシー：ホイールベース 3.9、連結点は後軸の 0.35 前。物理（`RIGP`）の値と同じで、変えない。

## 4. 形を作る道具

新しいファイル `src/06a-modelkit.js` に置く。THREE だけに頼り、画面（DOM）には触れないので、Node のテストで形を確かめられる。

| 道具 | 役目 |
| --- | --- |
| `sweep(profile, path, opts)` | 断面の線を道筋に沿って動かして面を作る。ダッシュボード、トリムの帯、ひさし、フェンダー |
| `loft(rings, opts)` | 点の数がそろった輪を順につないで面を作る。シート、キャブ、ミラーの殻、ハンドルのパッド |
| `roundBox(w, h, d, r, seg)` | 角を丸めた箱。収納、コンソール、引き出し、バッテリー箱 |
| `panel(outline, depth, bevel)` | 輪郭を押し出して縁を丸めた板。ドアの内張り、収納の扉、スイッチ、泥よけ |
| `lathe(profile, seg)`・`tube(points, r, seg)` | 回転体と管。ホイール、タンク、ランプ、手すり、レバー |
| `creaseNormals(geo, deg)` | なめらかな面と、角として残す折れ目を分ける |
| `shade(geo, fn)` | 頂点ごとの明るさを決める。すき間、足元、奥まった所を暗くする |
| `triCount(geo)` | 三角形の数を数える（上限のテスト用） |

- 細かさ：すべての道具は、分割数に細かさの係数 `DETAIL` を掛ける。画質「高」1.0、「中」0.6、「低」0.35。
- 面の向き：どの道具も、外側を向いた面を作る。法線の長さは 1。座標と法線に壊れた値（NaN）を出さない。
- UV：`sweep` と `loft` は、道筋方向と断面方向の実寸（m）を UV にする。革のしぼやステッチの大きさが部品ごとに変わらないようにするため。
- まとめ描き：今ある `Parts`（同じ素材の形を 1 つにまとめる仕組み）を引き続き使う。

## 5. 素材と光

新しいファイル `src/06b-materials.js` に、車両の素材をまとめる。今の `TM`（外装）と `IM`（内装）の名前のうち、ほかのファイルが使っているものは残す（9 章）。

### 5.1 素材の種類

| 素材 | 見え方 | 使う場所 |
| --- | --- | --- |
| 塗装 | 艶のあるクリア塗装。空が映る | キャブ、バンパー上部、ミラーカバー、フェンダー |
| 艶消しの樹脂 | 細かいしぼ。ほとんど映らない | ダッシュ上面、ピラー、バンパー下部、ステップ |
| 艶のある黒 | 窓や画面がぼんやり映る | センターパネルの帯、画面の縁、グリルの奥 |
| 革 | 細かいしぼ、縫い目（ステッチ） | シート、ハンドル、ひじ掛け、ドアの内張り |
| キルティング | ひし形の縫い目のふくらみ | 赤い内装の壁・天井・ドア |
| 布 | 織り目。映らない | 天井、カーテン、マットレス |
| ゴム | 縞板模様 | 床のマット、ペダル、ステップの面 |
| アルミ調 | 細い筋（ヘアライン） | ダッシュの細い線、吹き出し口の縁、取っ手 |
| 磨いたアルミ・メッキ | 周りをはっきり映す | ホイール、燃料タンク、飾り付きのグリルとミラー |
| ガラス | 外からは暗く映り込み、内からは薄い色 | 窓、ランプのレンズ |
| 光る素材 | 自分で光る | 画面、計器、灯火、赤い間接照明 |

### 5.2 質感の作り方

- 模様（革のしぼ、縫い目、キルティング、織り目、縞板、ヘアライン）は、コードで絵を描いて作る。大きさは画質「高」512、「中」「低」256。
- 凹凸は、同じ絵から作る「凹凸の地図」（法線マップ）で出す。画質「低」では使わない。
- 画質「高」「中」は、粗さと金属らしさで見え方が決まる素材（THREE の Standard／Physical）を使う。塗装にはクリア層を足す。
- 画質「低」は、今と同じ軽い素材（Lambert／Phong）を使う。形と色は同じ。
- 色の計算のしかた（出力の変換）は変えない。車両以外の見え方を変えないため。

### 5.3 光

- 外装の映り込み：空・地平線・地面を描いた「まわりの絵」（環境マップ）を、車両専用に新しく 1 枚作る（1 面 128 ピクセル。太陽の側を明るくする）。今ある 32 ピクセルの絵は、水面や周りの車が使っているので、そのまま残す。
- 室内の光：室内専用の「まわりの絵」を持つ。前（フロントガラス）と左右（ドアの窓）が明るく、床・後ろ・天井が暗い絵。これを室内の素材に当てると、窓の側が明るく、奥が暗い自然な陰影になる。
- 昼と夜：2 枚の絵の効きの強さを、時刻（`TOD.night`）とトンネルに合わせて変える。夜は弱め、計器・画面・赤い間接照明の光が主役になる。
- すき間の暗さ：`shade` で頂点に暗さを付ける（足元、シートとコンソールの間、収納の奥、ダッシュの下）。
- 太陽の影：今ある影（画質「高」「中」）はそのまま使う。
- 夜の赤い間接照明：今の `setCabAmbient` の仕組みを保ち、足元に加えて頭上の棚の下にも赤い帯を足す。

- 新しく足すもの：`applyTrim(name)`、`trimName`、`setCabDetail(inCab)`（外の視点で細かい部品を隠す）、`setVehicleLight(day, tunnel)`（まわりの絵の効きを時刻に合わせる）。

## 10. 確かめ方

### 10.1 写真と同じ角度で比べる

写真ごとに、カメラの位置と向き、内装・外装色・仕様・時刻を決めた「基準の視点」を 9 つ用意する。画面を撮り、写真と左右に並べた比較画像を作る。区切り（室内の前半分、後ろ半分、外観、飾り付き）ごとに撮り直し、ユーザーに見せる。写真そのものはリポジトリに入れない。

| --- | --- | --- | --- |
| R1 | 1（夜の運転席を後ろから） | ブラック、夜 | 回り込んだダッシュ、計器とセンターの 2 つの画面の光、ハンドルと中央パッド、足元の赤い光、2 つのシートの背、頭上の棚の赤い帯 |
| R2 | 2（助手席側から後ろを見る） | ライトグレー、昼 | 背の高い黒いシートと張り出し、ベッドと下の引き出し、後ろの壁の上の収納、明るい灰色の壁と天井、ドアの内張り |

## 11. エラーへの備え

- 質感のある素材が使えない（端末が対応していない、作るときにエラーが出た）：画質「低」の軽い素材に自動で切り替えて、ゲームは続く。
- 模様の絵が作れない：その素材は単色になる。
- 保存された外装の仕様・外装色・内装の名前が知らない値：初期値（`normal`、白、ブラック）を使う。
- 設定の保存に失敗しても、ゲームは続く（今の `lsGet`／`lsSet` と同じ扱い）。

## 12. 完成の基準

- V1〜V11 の自動テストがすべて通る。
- 今ある 77 件のテストが通り続ける。
- 基準の視点 R1〜R9 の比較画像で、「画面に見えるべきもの」がすべて見分けられる。
- 画質 高・中・低のどれでも、ゲームが始まり、連結から納品まで遊べる。
- README の車両の説明を、新しい内容（仕様の切り替え、内装の名前）に直す。
- 実機のスマホでの速さは、この環境では測れない。公開ページを更新し、重いときは画質「低」で試してもらう。
