# ニッポン長距離便（Nippon Long Haul）

ブラウザで遊べる、日本の高速道路を走るトラック運転ゲームです。
スカニア風のキャブオーバー車（日本向けの右ハンドル）で、東名高速の東京から名古屋まで荷物を運びます。

- 東名高速をモデルにした道路（縮尺1:10）。左側通行、片側2車線
- 区間ごとの景色：都市部の防音壁、御殿場の山と杉林、由比の海岸、牧之原の茶畑、浜名湖、11月の紅葉
- トンネル（都夫良野・日本坂・宇利）：オレンジ色の照明、法枠のある切土、坑口の名板
- 各ICに左側の出口ランプとETC料金所。ゲートは20km/h以下で通過
- 案内標識（出口予告・距離・キロポスト）、速度標識、車間距離確認板、LED情報板
- 周りの車：軽自動車、セダン、ミニバン、大型トラック、高速バス、軽トラ。追い越しのあとは左車線に戻る
- 車内：計器盤（速度計・回転計・ギア表示）、ナビ画面、3本スポークのハンドル、ペダル、ETC車載器、日よけ、カーテン、寝台、お守り
- ミラーは後ろの景色をリアルタイムで映す
- 12速の自動変速、リターダー、クルーズコントロール、90km/hのスピードリミッター、トレーラーの動き
- 合成したエンジン音・ウインカー音・ホーン・ETCのチャイム
- 時刻が進み、夕方から夜になるとライトが点く

## 車両（スカニアSシリーズの写真をもとに再現）

- 外装：角の丸いハイルーフキャブ、回り込んだフロントガラス、横スラットのグリル、バンパー角のLEDヘッドライト、大きなサンバイザーとライトバー、車体色のミラーカバー
- 後ろ側：コーナーピラーの赤いLEDストリップ、キャットウォーク（縞板）、黄・赤・黒のカールコード、サイドスカート、黒いリアフェンダーと大型後部反射器（赤とオレンジの斜めじま）
- 内装：今のスカニアと同じ配置。計器画面、ドライバー側に向いたセンターパネル（ナビ画面・スイッチ・エアコン）、カップホルダー付きのセンターコンソール、背の高い革シート、引き出し付きベッド、天井と後ろの収納、夜は赤い足元ライト
- メニューで外装色（白・青・赤・銀）と内装（ブラック・ベージュ・レッドのキルティング）を選べる

スカニアのロゴや社名は入れていません（グリルや後ろの文字の場所は空けてあります）。会社名「日之出運輸」は架空です。

## 操作

| 操作 | PC | スマホ |
| --- | --- | --- |
| アクセル / ブレーキ | W / S（Space で強いブレーキ） | 右下のペダル（下の方を押すほど強い） |
| ハンドル | A / D | 左下のハンドルを回す |
| ウインカー | Q / E | 左・右ボタン |
| クルーズ | C（+ / - で速度調整） | クルーズボタン |
| 視点 | V（1・2・3で直接） | 視点ボタン |
| 見回し | マウスでドラッグ | 画面をなぞる（2回タップで戻す） |
| 前進 / 後退 | R | D ボタン |
| ライト / ワイパー / ハザード / ホーン | L / P / F / H | 上のボタン |

ハンドルコントローラーやゲームパッド（Gamepad API）にも簡易対応しています。

## ファイル構成

```
src/page.html      画面のHTMLとCSS
src/01-util.js     数学・乱数・ジオメトリ結合
src/02-route.js    道路の線形、IC、トンネル、出口ランプ、標識の配置
src/03-gfx.js      レンダラー、画質設定、テクスチャ、マテリアル
src/04-sky.js      空、遠くの山、富士山、雲、時刻と光
src/05-world.js    200mごとの地形・道路・建物・トンネル・料金所・標識
src/06-truck.js    トラクターとトレーラーの外観
src/07-interior.js 車内
src/08-dash.js     計器盤・ナビ画面・ミラー
src/09-physics.js  エンジン・変速・ブレーキ・操舵・トレーラー
src/10-traffic.js  周りの車
src/11-audio.js    効果音
src/12-input.js    キーボード・タッチ・ゲームパッド
src/13-game.js     仕事の進行、カメラ、表示、メインループ
build.mjs          src を index.html 1ファイルにまとめる
```

`node build.mjs` で `index.html` を作り直します。Three.js r128 を cdnjs から読み込みます。
