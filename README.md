# ニッポン長距離便（Nippon Long Haul）

ブラウザで遊べる、日本の高速道路を走るトラック運転ゲームです。
スカニア風のキャブオーバー車（日本向けの右ハンドル）で、東名高速の東京から名古屋まで荷物を運びます。

- 東名高速をモデルにした道路（縮尺1:10）。左側通行、片側2車線
- 区間ごとの景色：都市部の防音壁、御殿場の山と杉林、由比の海岸、牧之原の茶畑、浜名湖、11月の紅葉
- トンネル（都夫良野・日本坂・宇利）：オレンジ色の照明、法枠のある切土、坑口の名板
- 各ICに左側の出口ランプとETC料金所。ゲートは20km/h以下で通過。その先に納品の枠がある
- 案内標識（出口予告・距離・キロポスト）、速度標識、車間距離確認板、LED情報板
- 周りの車：軽自動車、セダン、ミニバン、大型トラック、高速バス、軽トラ。追い越しのあとは左車線に戻る
- 車内：計器盤（速度計・回転計・ギア表示）、ナビ画面、3本スポークのハンドル、ペダル、ETC車載器、日よけ、カーテン、寝台、お守り
- ミラーは後ろの景色をリアルタイムで映す
- 12速の自動変速、リターダー、クルーズコントロール、90km/hのスピードリミッター
- 荷物の重さとタイヤのグリップにもとづく連結車両の挙動（下の「牽引の重さと挙動」）
- 合成したエンジン音・ウインカー音・ホーン・ETCのチャイム・連結の音・タイヤの鳴く音
- 時刻が進み、夕方から夜になるとライトが点く

## 車両（スカニアSシリーズの写真をもとに再現）

- 外装：角の丸いハイルーフキャブ、回り込んだフロントガラス、横スラットのグリル、バンパー角のLEDヘッドライト、大きなサンバイザーとライトバー、車体色のミラーカバー
- 後ろ側：コーナーピラーの赤いLEDストリップ、キャットウォーク（縞板）、黄・赤・黒のカールコード、サイドスカート、黒いリアフェンダーと大型後部反射器（赤とオレンジの斜めじま）
- 内装：今のスカニアと同じ配置。計器画面、ドライバー側に向いたセンターパネル（ナビ画面・スイッチ・エアコン）、カップホルダー付きのセンターコンソール、背の高い革シート、引き出し付きベッド、天井と後ろの収納、夜は赤い足元ライト
- メニューで外装色（白・青・赤・銀）と内装（ブラック・ベージュ・レッドのキルティング）を選べる

スカニアのロゴや社名は入れていません（グリルや後ろの文字の場所は空けてあります）。会社名「日之出運輸」は架空です。

## 牽引の重さと挙動

仕事は、トラクターだけで路肩から始まります。後ろのトレーラーにバックして連結し、目的地の料金所の先にある納品の枠で切り離すと完了です。

| 仕事 | 荷物 | トレーラー | 総重量 |
| --- | --- | --- | --- |
| 東京 → 御殿場 | 精密機器 12 t | バン | 26.6 t |
| 御殿場 → 静岡 | 牛乳 19 t | タンク | 33.1 t |
| 静岡 → 浜松 | 飲料 22 t | バン | 36.6 t |
| 浜松 → 名古屋 | 楽器 9 t | バン | 23.6 t |

- **重さ**：総重量は「トラクター 7.6 t + 空のトレーラー + 荷物」。重いほど加速が鈍く、坂で速度が落ち、同じ踏み方では止まりにくくなります。0→80 km/h は空車で約11秒、26.6 t で約25秒、36.6 t で約35秒です。
- **連結**：第五輪をキングピンに、横のずれ 20 cm 以内、向きの差 10° 以内、5.4 km/h 以下で合わせるとロックします。ホース接続と脚上げに2秒かかります。止まって `T` を押すと自動で連結します。
- **タイヤ**：車軸ごとの荷重からグリップの限界を計算します。ブレーキや駆動で前後に力を使うほど、横に踏ん張れなくなります。
- **ジャックナイフと横転**：安定装置を切ると、軽いトレーラーで強く踏んだときに駆動軸がロックして折れ曲がり、重心の高い荷物は速すぎる旋回で横転します。どちらもレッカー移動になり、違反金がかかります。
- **タンク**：液体の一部が中で動きます。止まったあと前後に押され、カーブでは外へ余計に傾きます。
- **安定装置**（最初はオン。メニューで切り替え）：ABS、空転防止、横滑り防止、横転防止、切りすぎ防止。作動中はメーターのランプが点滅します。

## 操作

| 操作 | PC | スマホ |
| --- | --- | --- |
| アクセル / ブレーキ | W / S（Space で強いブレーキ） | 右下のペダル（下の方を押すほど強い） |
| ハンドル | A / D | 左下のハンドルを回す |
| ウインカー | Q / E | 左・右ボタン |
| クルーズ | C（+ / - で速度調整） | クルーズボタン |
| 視点 | V（1・2・3で直接） | 視点ボタン |
| 見回し | マウスでドラッグ | 画面をなぞる（2回タップで戻す） |
| 前進 / 後退 | R | D ボタン |
| 連結 / 切り離し | T | 上の「自動連結」「切り離し」ボタン |
| ライト / ワイパー / ハザード / ホーン | L / P / F / H | 上のボタン |

ハンドルコントローラーやゲームパッド（Gamepad API）にも簡易対応しています。

## ファイル構成

```
src/page.html      画面のHTMLとCSS
src/01a-math.js    数学・乱数・ノイズ（画面を使わない）
src/01b-three.js   保存・キャンバス・ジオメトリ結合
src/02-route.js    道路の線形、IC、トンネル、出口ランプ、納品の枠、標識の配置
src/03-gfx.js      レンダラー、画質設定、テクスチャ、マテリアル
src/04-sky.js      空、遠くの山、富士山、雲、時刻と光
src/05-world.js    200mごとの地形・道路・建物・トンネル・料金所・標識
src/06-truck.js    トラクターとトレーラーの外観
src/07-interior.js 車内
src/08-dash.js     計器盤・ナビ画面・ミラー
src/09a-powertrain.js エンジン・変速・リターダー・クルーズ
src/09b-rig.js     連結車両の力学（タイヤ、連結点、傾き、液体の揺れ、安定装置、接触）
src/09c-truck.js   車両の状態、配置、連結と切り離し
src/10-traffic.js  周りの車
src/11-audio.js    効果音
src/12-input.js    キーボード・タッチ・ゲームパッド
src/13-game.js     仕事の進行、カメラ、表示、メインループ
build.mjs          src を index.html 1ファイルにまとめる
test/              自動テスト（Node）と、ブラウザの通し確認（test/e2e）
docs/superpowers/  設計書と実装計画
```

`npm run build`（`node build.mjs`）で `index.html` を作り直します。Three.js r128 を cdnjs から読み込みます。

## テスト

```
npm install      # テスト用の three r128 を入れる
npm test         # 物理の自動テスト（Node だけで動く）
npm run e2e      # ビルドして、ヘッドレスのブラウザで連結から納品までを確認する（Playwright が必要）
```

物理のファイル（`01a`、`02`、`09a`〜`09c`）は画面の API を使わないので、Node でそのまま読み込んでテストします。
