# ニッポン長距離便（Nippon Long Haul）

ブラウザで遊べる、日本の高速道路を走るトラック運転ゲームです。
欧州製キャブオーバー風のトラクター（日本向けの右ハンドル）で、東名高速の東京から名古屋まで荷物を運びます。

- 東名高速をモデルにした道路（縮尺1:10）。左側通行、片側2車線
- 区間ごとの景色：都市部の防音壁、御殿場の山と杉林、由比の海岸、牧之原の茶畑、浜名湖、11月の紅葉
- トンネル（都夫良野・日本坂・宇利）：オレンジ色の照明、法枠のある切土、坑口の名板
- 13 の IC すべてに町：料金所広場（ETC のゲートは 20 km/h 以下で開く）、大通りと脇道、信号と「止まれ」の交差点、町の車、家・店・工場、2〜3 か所の倉庫（荷台口と納品の枠）
- 各 IC に左側の出口ランプと入口ランプ（合流の帯）。目的地でない IC で降りても、罰金なしで入口から高速に戻れる
- 町の決まり：赤信号で停止線を越えると罰金 ¥9,000。制限速度は大通り 50、脇道 40、料金所広場と倉庫の構内 20 km/h
- ナビ：町の中では次に曲がる交差点の矢印と距離（300 m 手前から）、大通りではどちらの車線を走るか、通る道を青い線で。高速では目的の出口の 2km の標識から「〇〇IC 出口　左車線へ」。道を外れたら自動で探し直す（「ルートを探し直しました」）。道は大通り優先・右折少なめで選ぶ
- 案内の札：どの視点でも、画面の右上に次の操作・距離・車線の小さな札が出る（曲がる手前、出口の手前、料金所広場、構内）
- 全体地図：「地図」ボタン（PC は M キー）で開くとゲームが止まり、東名の全体と 13 の IC、今いる町（高速では目的の町）の道と通る道が見られる
- 途中保存：運転中は 10 秒ごと（とページを閉じるとき）に保存し、次に開くと同じ場所・向き・連結の状態から続けられる
- 案内標識（出口予告・距離・キロポスト）、速度標識、車間距離確認板、LED情報板
- 周りの車：軽自動車、セダン、ミニバン、大型トラック、高速バス、軽トラ。追い越しのあとは左車線に戻る
- 車内：計器盤（速度計・回転計・ギア表示）、ナビ画面、3本スポークのハンドル、ペダル、ETC車載器、日よけ、カーテン、寝台、お守り（下の「車両」）
- ミラーは後ろの景色をリアルタイムで映す
- 12速の自動変速、リターダー、クルーズコントロール、90km/hのスピードリミッター
- 荷物の重さとタイヤのグリップにもとづく連結車両の挙動（下の「牽引の重さと挙動」）
- 合成したエンジン音・ウインカー音・ホーン・ETCのチャイム・連結の音・タイヤの鳴く音
- 時刻が進み、夕方から夜になるとライトが点く

## 車両（写真 9 枚をもとに作り直した姿）

形はすべてコードで作っています（外の 3D モデルや画像ファイルは使いません）。部品は箱の組み合わせではなく、断面をつないだ曲面です。

- **室内**（運転席から見える範囲を最優先）：ドライバー側に回り込んだダッシュ、計器とセンターの 2 つの画面、革巻きの 3 本スポークのハンドル、ドアの内張りと窓のスイッチ、背の高い一体型の革シート（縫い目つき）、頭上の棚、天井、引き出し付きのベッド、カーテン、お守り。夜は足元と頭上の棚が光ります。
- **内装の 3 種類**（メニューで選択）：ブラック、ライトグレー（明るい灰色の壁と天井）、レッド（赤いキルティングの壁と天井、赤いステッチ）。
- **外観**：角の丸いハイルーフキャブ、回り込んだフロントガラス、台形のグリルと横スラット、角のLEDヘッドライト、大きなサンバイザー、ミラー、ステップ、サイドの整流板、シャシー、燃料タンク、車輪（ナット・ハブ・穴あきのホイール）。
- **外装の仕様**（メニューで切り替え）：「ノーマル」は写真のままの姿。「飾り付き」は屋根のライトバーと丸いランプ 6 個（ライトと一緒に点く）、バイザーとバンパーのオレンジのマーカー、クロームのグリルとミラーカバー、ナットキャップ、キャブの横と前の線模様（白・銀には紺、青・赤には金）。
- **外装色**：白・青・赤・銀。塗装には周りの景色が映り込みます。
- **素材と光**：革・樹脂・布・ゴム・金属・塗装・ガラスの質感（凹凸の模様と映り込み）。昼は窓から光が入り、夜やトンネルでは暗くなります。
- **画質**（高・中・低）：曲面の細かさと質感が変わります。低は軽い描き方で、スマホ向けです。

ロゴや社名は入れていません（グリル、キャブの後ろ、泥よけ、ハンドル中央は無地です）。会社名「日之出運輸」は架空です。

## 牽引の重さと挙動

仕事は、出発の町の倉庫から始まります。トレーラーは構内の置き場にあり、トラクターはその 12 m 前に止まっています。バックして連結し、町の道を走って料金所広場の入口ゲートから高速へ入ります。目的の IC で降り、出口ゲートで ETC 料金を払って、町の中の目的の倉庫へ向かいます。

- **荷台口**：建物の荷台口にバックで付けて切り離すと、報酬が 20% 増えます（後ろの端が荷台口から 0.6 m 以内、横のずれ 0.5 m 以内、向きの差 4° 以内）。
- **納品の枠**：門から入って構内を横切り、前から入る 4 m × 18 m の枠で切り離しても納品になります。
- 目的の出口を通り過ぎると、次の IC が目的地になります（報酬が 15% 減ります）。

| 番号 | 仕事 | 荷物 | トレーラー | 総重量 |
| --- | --- | --- | --- | --- |
| 1 | 東京 → 厚木 | 精密機器 12 t | バン | 26.6 t |
| 2 | 厚木 → 御殿場 | 飲料 20 t | バン | 34.6 t |
| 3 | 御殿場 → 富士 | 牛乳 19 t | タンク | 33.1 t |
| 4 | 富士 → 静岡 | 紙製品 15 t | バン | 29.6 t |
| 5 | 静岡 → 掛川 | 緑茶 10 t | バン | 24.6 t |
| 6 | 掛川 → 浜松 | 食用油 18 t | タンク | 32.1 t |
| 7 | 浜松 → 岡崎 | 楽器（ピアノ） 9 t | バン | 23.6 t |
| 8 | 岡崎 → 名古屋 | 自動車部品 22 t | バン | 36.6 t |
| 9 | 東京 → 横浜町田 | 日用品 8 t | バン | 22.6 t |
| 10 | 横浜町田 → 大井松田 | 冷凍食品 16 t | バン | 30.6 t |
| 11 | 大井松田 → 沼津 | 水 21 t | タンク | 35.1 t |
| 12 | 沼津 → 豊川 | 魚の加工品 14 t | バン | 28.6 t |
| 13 | 豊川 → 名古屋 | 機械部品 18 t | バン | 32.6 t |

- **重さ**：総重量は「トラクター 7.6 t + 空のトレーラー + 荷物」。重いほど加速が鈍く、坂で速度が落ち、同じ踏み方では止まりにくくなります。0→80 km/h は空車で約11秒、26.6 t で約25秒、36.6 t で約35秒です。
- **連結**：第五輪をキングピンに、横のずれ 20 cm 以内、向きの差 10° 以内、5.4 km/h 以下で合わせるとロックします。ホース接続と脚上げに2秒かかります。止まって `T` を押すと自動で連結します。
- **タイヤ**：車軸ごとの荷重からグリップの限界を計算します。ブレーキや駆動で前後に力を使うほど、横に踏ん張れなくなります。
- **ジャックナイフと横転**：安定装置を切ると、軽いトレーラーで強く踏んだときに駆動軸がロックして折れ曲がり、重心の高い荷物は速すぎる旋回で横転します。どちらもレッカー移動になり、違反金がかかります。
- **タンク**：液体の一部が中で動きます。止まったあと前後に押され、カーブでは外へ余計に傾きます。
- **安定装置**（最初はオン。メニューで切り替え）：ABS、空転防止、横滑り防止、横転防止、切りすぎ防止。作動中はメーターのランプが点滅します。

## 操作

| 操作 | PC | スマホ |
| --- | --- | --- |
| アクセル / ブレーキ | W / S（Space で強いブレーキ） | 右下のペダル（下の方を押すほど強い） |
| ハンドル | A / D | 左下のハンドルを回す |
| ウインカー | Q / E | 左・右ボタン |
| クルーズ | C（+ / - で速度調整） | クルーズボタン |
| 視点 | V（1・2・3で直接） | 視点ボタン |
| 見回し | マウスでドラッグ | 画面をなぞる（2回タップで戻す） |
| 前進 / 後退 | R | D ボタン |
| 連結 / 切り離し | T | 上の「自動連結」「切り離し」ボタン |
| 全体地図 | M | 上の「地図」ボタン |
| ライト / ワイパー / ハザード / ホーン | L / P / F / H | 上のボタン |

ハンドルコントローラーやゲームパッド（Gamepad API）にも簡易対応しています。

build.mjs          src を index.html 1ファイルにまとめる
tools/refshot.mjs  写真と同じ角度で車両を撮り、比較画像を作る（写真はリポジトリに入れない）

`npm run build`（`node build.mjs`）で `index.html` を作り直します。Three.js r128 を cdnjs から読み込みます。

## テスト

```
npm install      # テスト用の three r128 を入れる
npm test         # 物理の自動テスト（Node だけで動く）
npm run e2e      # ビルドして、ヘッドレスのブラウザで倉庫の連結から町の納品までを確認する（Playwright が必要）
```

自動テストは 108 件、ブラウザでの確認は 91 件（車両の見た目・室内・外観・上限、メーター、町の見た目と上限、料金所、信号、荷台口、途中保存、ナビの案内と全体地図、通しの運転など）です。ブラウザの確認は全部で 50 分ほどかかります。

物理と町のルールのファイル（`01a`、`02`〜`02d`、`09a`〜`09c`）と形を作る道具（`06a`）は画面の API を使わないので、Node でそのまま読み込んでテストします。

車両の見た目は、写真と同じ 9 つの角度（R1〜R9）で撮って確かめます。

```
node tools/refshot.mjs all             # out/refshots/R1.png … R9.png を撮る（--q mid / low で画質を変える）
REF_PHOTOS=写真のフォルダ node tools/refshot.mjs all   # 1.jpg〜9.jpg と並べた比較画像も作る
```
